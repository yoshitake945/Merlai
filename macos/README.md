# Merlai for Logic Pro

Apple Silicon、macOS 14以上を対象にしたローカル作曲アシスタントです。ビルドにはRust stable、Cargo、Swift 5.9以上のAppleツールチェーンを使用します。

```sh
scripts/build-macos.sh
open dist/Merlai.app
```

「メロディーMIDIを開く」で短いリージョンを選びます。自作の例は `tests/native/melody.mid` です。必要ならドラムを追加し、キックのノート番号を指定してください。DOPEの実機素材では36と37を使用しました。音源を選んで「音色を選んで計測」を押すと、音源の画面でプリセットを選べます。生成後は各案を元メロディーに続けて試聴し、候補をLogicの新規ソフトウェア音源トラックへドラッグします。Logic側でも同じ音色を選びます。FinderからもMIDIを取り込めます。

## ローカル処理

SwiftUIからRust CLIに標準入力でJSONを渡します。Rustは末尾2小節の音列を取り出し、発音位置、音程順、終止音を変えて3案を書き出します。拍の解像度を揃えた任意のドラムループでキック付近の打点を間引きます。単旋律向けで、途中にテンポ・拍子変更のある素材は分割して渡してください。先頭の完全な空小節を取り除き、小節内の休符は保持します。主音の初期値は先頭音です。

CLI契約の例（リポジトリのルートで実行。outputは新しいディレクトリ名）。

```sh
echo '{"version":1,"melody":"tests/native/melody.mid","drums":"tests/native/groove.mid","output":"take-01","bars":2,"seed":0,"kicks":[36],"tonic":6,"attack_ms":0,"release_ms":0}' | cargo run --locked -q -p merlai-compose
```

応答はversion、ppq、四分音符当たりマイクロ秒のtempo、続きの開始tick、元のノート列、候補のパスとノート列です。候補ファイルの原点はリージョンの先頭です。アプリ生成物と試聴キャッシュは一時ディレクトリに置き、採用時にLogicへ取り込みます。

Swift音源ホストは選択したAudio Unitを別プロセスで開き、C4・ベロシティ90の信号をオフラインで計測します。10 ms単位のピークから立ち上がりと余韻を推定します。75 ms以上の立ち上がりでは密度を下げ、300 ms以上の余韻では音長を短縮します。SQLiteカタログと音源ごとの最後のプリセット状態はApplication Support/Merlaiに保存します。画面操作権限は不要です。

## 検証とリリース

`cargo test --locked` でMIDIを再読込し、発音・長さ・再現性・タイミング補正を検査します。GitHub ActionsはRustテストとMacアプリのビルド・署名検証を実行します。ローカルビルドはアドホック署名です。実機検証後にmacos-vから始まるタグを付けるとドラフトReleaseを作成します。

M1でDOPE実素材と自作メロディーから12音の候補を生成し、Analog Lab Vの初期音色で元メロディーと続きのステレオ音声を生成できました。10.44秒の音声でホスト起動を含めて1.34秒、ホスト単体の最大RSSは約202 MiBでした。Logicの「読み込む」で既存テンポを保持し、新規音源トラックの13〜15小節に候補が配置され、ピアノロールでノートが表示されることを確認しました。アプリからの直接ドラッグ、Logic側での試聴、選択したプリセットの再現性は追加の実機検証項目です。

### 素材のドロップと別テイク

Finderからメロディーとドラムの各入力欄へ、MIDIファイルを1つずつドロップできます。「別テイクを生成」で同じ素材をもう一度展開し、「テイク」で以前の3案に戻って試聴・取り込みできます。素材を変えたり音色を再計測したりする前に、残したい候補を制作フォルダへコピーしてください。
