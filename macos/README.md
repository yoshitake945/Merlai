# Logic Proで続きを作る

[Merlaiのビルドと起動](../README.md) が済んだら、一定のテンポ・拍子の短い単旋律をLogicからMIDIファイルに書き出します。[同梱のメロディー](../tests/native/melody.mid) でも試せます。

1. **素材を開く。** 「メロディーMIDIを開く」でファイルを選びます。キックとシンセの打点をずらしたいときは「ドラムMIDIを開く」でドラムを追加します。[同梱のドラム](../tests/native/groove.mid) のキック番号は `36` です。実機で試したBM-DOPEの素材では `36,37` を使いました。他のキットでは割り当てを確認してください。ドラムMIDIを選ぶと「ドラム音源」が表示されます。BM-DOPEやBM-KANDYを選ぶと、メロディー候補と同じ試聴音声にドラムもミックスされます。
2. **長さと音色を決める。** 生成する長さは1〜16小節、初期値は2小節です。主音の初期値にはメロディーの先頭音を使います。試聴する場合は「音源」でAudio Unitを選び、「音色を選んで計測」でプリセットを決めます。画面に立ち上がりと余韻が表示されたら生成に進みます。保存済みの音色は次回起動時にもプロファイルが読み込まれ、「保存済み音色」と表示されます。
3. **候補を選ぶ。** 「続きを3案生成」を押します。音源を選んだ場合は「試聴」で元メロディーから候補へ続けて聴けます。ドラム音源も選んだ場合は、入力したドラムMIDIが曲の全区間で繰り返され、同じ音声にミックスされます。「MIDIのみ」でも3案を書き出せます。
4. **採用するテイクを選ぶ。** 最初の生成後にボタンが「別テイクを生成」に変わります。押すと「テイク 2」が選ばれ、さらに3案できます。「テイク」で戻って比較できます。採用するテイクを表示した状態で、候補の行にある「Finderで表示」を押してください。たとえばテイク2・候補2なら、Finderで `candidate-2.mid` が選択されます。各テイクは別フォルダに同じファイル名を使うため、このボタンからたどると目的の候補を選べます。

## Logicで目的の小節に置いて再生する

以下は日本語表示のLogic Proで確認した手順です。例では31小節目に2小節の候補を置きます。自分の曲では、続きを始めたい小節に読み替えてください。

1. Finderで選択中の候補のパスをコピーします（⌥⌘C）。保管したい場合は、先に制作フォルダへ候補をコピーし、そのコピーを選びます。
2. Logicのトラック領域に戻り、ルーラで配置したい小節の頭をクリックします。正確に指定するには、この検証環境では `/` で「位置の移動」を開き、`31 1 1 1` を入力してReturnを押せました。上部の再生ヘッド位置で31小節・1拍目になったことを確認します。
3. **⌘I** で「読み込む」を開きます。**⇧⌘G** でファイルのパスを貼り付け、Returnを押します。選択されたファイル名を確認し、「読み込む」をクリックします。
4. **「テンポ情報も読み込みますか？」** と表示されたら、曲の現在のテンポで鳴らす場合は **「いいえ」** を選びます。
5. トラック領域でMIDIリージョンを確認します。例ではStudio Grandトラックの31小節頭から33小節頭までに入りました。別の音源で鳴らすときは、開始小節を保ったまま目的のソフトウェア音源トラックへ移し、Logic側でプリセットを選びます。
6. リージョンをダブルクリックするとピアノロールで音程やタイミングを確認・編集できます。再生ヘッドを開始小節に合わせ、スペースキーで再生し、もう一度押して停止します。

### うまくいかないとき

| 状況 | 確認する場所 |
| --- | --- |
| 「続きを3案生成」を押せない | 「メロディーMIDIを開く」の右にファイル名が表示されているか確認します。ドラム入力は任意です。 |
| Merlaiの「試聴」を押せない | 「音源」が「MIDIのみ」なら、Audio Unitを選んでから生成します。MIDIのみで作った候補はLogic側のソフトウェア音源で再生できます。 |
| 欲しい候補と違う | 「テイク」を選び直してから、その候補の「Finderで表示」を押します。 |
| Logicで違う音色が鳴る | 読み込み先のトラックと音源スロットを確認します。MIDIにはMerlaiで選んだプリセットは含まれません。 |

候補のラベルからLogicへ直接ドラッグできます。ドラッグ項目は標準MIDIファイルとして渡されるため、Logicのソフトウェア音源トラック上の目的位置へドロップしてください。生成ファイルと試聴音声の保存先は一時フォルダです。後日使うMIDIはLogicに取り込むか、「Finderで表示」から制作フォルダへコピーしてください。

## 実機で確認した範囲

M1 MacでDOPEのドラムを参照し、2小節・12音の候補を生成しました。Logicの新規音源トラックでは13小節の頭から15小節の頭までのリージョンになり、ピアノロールにノートが表示されました。Analog Lab Vの初期音色では10.44秒の試聴音声を1.34秒で書き出し、ホスト単体の最大RSSは約202 MiBでした。

マージ後のMac版でも、同梱メロディーからテイク2・候補2を生成し、Logicで31〜33小節への配置とスペースキーでの再生・停止、再生ヘッドの進行を確認しました。音色の聴感比較は行っていません。

直接ドラッグ、選択したプリセットの再現性、プラックとパッドの聴き比べは個別に追跡しています。[MIDI配置](https://github.com/yoshitake945/Merlai/issues/52)・[音源試聴](https://github.com/yoshitake945/Merlai/issues/53)・[音色とドラム](https://github.com/yoshitake945/Merlai/issues/54)

### 素材のドロップと別テイク

Finderからメロディーとドラムの各入力欄へ、MIDIファイルを1つずつドロップできます。「別テイクを生成」で同じ素材をもう一度展開し、「テイク」で以前の3案に戻って試聴・取り込みできます。素材を変えたり音色を再計測したりする前に、残したい候補を制作フォルダへコピーしてください。
