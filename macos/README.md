# Logic Proで続きを作る

[Merlaiのビルドと起動](../README.md) が済んだら、一定のテンポ・拍子の短い単旋律をLogicからMIDIファイルに書き出します。[同梱のメロディー](../tests/native/melody.mid) でも試せます。

1. **素材を開く。** 「メロディーMIDIを開く」でファイルを選びます。キックとシンセの打点をずらしたいときは「ドラムMIDIを開く」でドラムを追加します。[同梱のドラム](../tests/native/groove.mid) のキック番号は `36` です。実機で試したBM-DOPEの素材では `36,37` を使いました。他のキットでは割り当てを確認してください。
2. **長さと音色を決める。** 生成する長さは1〜16小節、初期値は2小節です。主音の初期値にはメロディーの先頭音を使います。試聴する場合は「音源」でAudio Unitを選び、「音色を選んで計測」でプリセットを決めます。画面に立ち上がりと余韻が表示されたら生成に進みます。
3. **候補を選ぶ。** 「続きを3案生成」を押します。音源を選んだ場合は「試聴」で元メロディーから候補へ続けて聴けます。「MIDIのみ」でも3案を書き出せます。
4. **Logicに配置する。** 実機で確認した方法は「Finderで表示」で候補ファイルを特定し、Logicで再生ヘッドを目的の小節に合わせ、「読み込む」でそのファイルを選ぶ方法です。テンポ情報を読み込むか聞かれたら、曲のテンポを維持するには「いいえ」を選びます。読み込み時に新規トラックができた場合は、目的の音源トラックへリージョンを移します。Merlaiと同じ音で鳴らすにはLogic側でも同じプリセットを選びます。

候補のラベルからLogicへ直接ドラッグする操作も実装しています。生成ファイルと試聴音声の保存先は一時フォルダです。後日使うMIDIはLogicに取り込むか、「Finderで表示」から制作フォルダへコピーしてください。

## 実機で確認した範囲

M1 MacでDOPEのドラムを参照し、2小節・12音の候補を生成しました。Logicの新規音源トラックでは13小節の頭から15小節の頭までのリージョンになり、ピアノロールにノートが表示されました。Analog Lab Vの初期音色では10.44秒の試聴音声を1.34秒で書き出し、ホスト単体の最大RSSは約202 MiBでした。

直接ドラッグ、選択したプリセットの再現性、プラックとパッドの聴き比べは個別に追跡しています。[MIDI配置](https://github.com/yoshitake945/Merlai/issues/52)・[音源試聴](https://github.com/yoshitake945/Merlai/issues/53)・[音色とドラム](https://github.com/yoshitake945/Merlai/issues/54)
