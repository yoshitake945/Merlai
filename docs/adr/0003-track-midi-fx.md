# 0003　Logicの音源トラックでフレーズを推敲する

**状態**　試作。Logic実曲での受け入れ検証中。

**背景**　外部アプリで音源を開く方式では、曲の中で使っているプリセットやチャンネルストリップの処理を再現する手間がある。生成したMIDIを読み込むたびにも操作が必要だった。

**判断**　既存音源の手前に挿すAUv2 MIDI Processorを追加する。取り込み元はこのスロットに到達したノート、範囲はホストのサイクルで指定する。プラグイン画面では、対応する日本語の編集指示をRustで処理し、変化を確認してから適用する。再生側は準備済みのイベントをサイクル先頭から送る。

**制約**　編集の対象は当該トラックのノート。別トラックの和声や音源の出力音声は自動解析しない。実際の音色との相性は曲を流しながら判断する。現在の編集と取り消し履歴は作業中の状態であり、採用する案はMIDIとして録音する。将来モデルを接続する場合も、編集の対象範囲と保護するノートを確認してから適用する。別トラックを文脈にした生成は、後継の[0004](0004-cross-track-context-generation.md)で扱う。
