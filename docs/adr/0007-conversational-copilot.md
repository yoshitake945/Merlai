# 0007　Logic内の会話型制作コパイロットへ集中する

**状態**　採用。

**背景**　Merlai内のMIDI編集は鍵盤表示と直接音確認が不足し、Logicのピアノロールと責務が重なる。一方、複数トラックの文脈、AIとの反復、変更理由、音色候補、利用量の可視化はLogic標準機能だけでは一つの制作ループにならない。

**判断**　Logicプラグインを主要画面とし、Merlaiの責務をContext、Conversation、Commitへ整理する。手動ノート編集はLogicへ委譲し、Merlaiには読み取り専用差分、試聴、候補履歴、AI再修正、確定を残す。

AIは入力の分析、候補生成、比較まで実行できるが、候補確定、Logicへの出力、クラウド送信はユーザー確認を必要とする。会話はプラグインインスタンス単位とし、別プロジェクトのContextを暗黙に混ぜない。

音色探索はローカル特徴抽出と決定的ランキングを先に行い、AIへは上位候補の圧縮特徴だけを渡す。任意のサードパーティ音源UIを自動操作しない。GenAI利用量はOpenTelemetryの属性へ正規化し、内容データは既定でTelemetryへ含めない。

**結果**　MerlaiはDAW機能を複製せず、Logic内で不足する文脈統合と会話型意思決定へ集中する。詳細な導入順序は[プロダクトロードマップ](../product-roadmap.md)とGitHub Milestone M4〜M7で追跡する。
