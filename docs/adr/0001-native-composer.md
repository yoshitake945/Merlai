# 0001　ローカル生成と音源ホストの分離

**状態**　採用済み。Mac版の実装後に判断を記録した。

**背景**　Logicでの制作中に短いMIDIを生成し、インストール済み音源で試聴したい。MIDI生成に必要な資源と、市販音源をロードするための資源は大きく異なる。

**判断**　SwiftUIがRustの生成CLIへJSONを送り、Audio Unitのロードとレンダリングは別のSwiftプロセスに任せる。標準MIDIを生成の成果物にする。

**結果**　音源がなくても候補を生成でき、同じ入力とシードで生成処理だけを検証できる。試聴には音源とプリセット状態の再現が必要になる。将来AIモデルを導入する際は、旧設計のモデル選択・失敗時の扱いを参照し、現在のMIDI入出力と比較できる形で検討する。[旧モデル管理設計](../history/python-ai-model-management.md)
