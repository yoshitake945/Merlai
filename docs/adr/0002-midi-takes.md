# 0002　MIDIファイルとテイクによる受け渡し

**背景**　同じ素材で候補を作り直しても固定シードでは同じ結果になり、前の候補は画面から消えていた。

**判断**　メロディーとドラムは各入力欄にMIDIファイルをドロップできるようにする。同じ素材で生成するたびにテイク番号に応じたシードを渡す。各テイクには生成先と試聴用音源を紐づけ、前の候補に戻って試聴・取り込みできるようにする。

**制約**　テイクはアプリ内の作業履歴で、素材の変更、音色の再計測、終了で履歴を閉じる。単音の繰り返しなどではシードを変えても音楽的に同じ結果になる場合がある。採用するMIDIはLogicに取り込むか、Finderから制作フォルダへ保存する。Logicの画面操作権限は要求しない。
